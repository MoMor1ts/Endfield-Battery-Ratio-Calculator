# 终末地 · 电池配比计算器

算《明日方舟：终末地》里「电池取货 → 分流 → 热能池」该怎么配比例、怎么搭。
输入耗电量和电池获取速率，输出两样东西：**每多少秒用一块电池**，以及一张**游戏内的网格蓝图**（直接照着摆）。

有两种形态，功能一致：

- **网页版**：`web/index.html` 单文件，手机/电脑双击就能开，图片全部内嵌。
- **桌面版**：`endfield_battery.py`，可用 `build_exe.bat` 打包成单文件 exe。

> 非官方工具，与鹰角网络无关。不收集任何数据，纯本地计算。

## 功能

- 五种电池（发电量自动带入）：谷底低容 220 / 谷底中容 420 / 谷底高容 1100 / 武陵低容 1600 / 武陵中容 3200（每秒）
- 电池获取速率滑轨：6 / 12 / 18 / 24 / 30 个每分钟
- **简单模式**：用 2 分、3 分的组合逼近理论比例
- **精确模式**：对比例做质因数分解，给出可精确复现的配方
- 三套配色：黄灰（默认）/ 白蓝 / 黄紫
- 右侧两种输出：**计算结果**（文字）和**搭建演示**（网格蓝图）

## 怎么用

### 网页版

1. 双击 `web/index.html`，用任意现代浏览器打开。
2. 手机上：把 `index.html` 传过去，用 Chrome 打开 → 菜单 → 「添加到主屏幕」，和 App 一样用。
   上传到任意静态托管（GitHub Pages 等）后，页面内置的 manifest 生效，添加到主屏幕是独立全屏。

| 参数 | 说明 |
|---|---|
| `power` | 系统总耗电 |
| `battery` | 电池序号 0~4（0 = 谷底低容 … 4 = 武陵中容） |
| `rate` | 速率 6 / 12 / 18 / 24 / 30 |
| `theme` | `huanghui` / `bailan` / `huangzi` |
| `mode` | `normal` / `precise` |
| `view` | `result` / `build` |
| `calc=1` | 打开后立刻计算一次 |

### 桌面版

```bash
python endfield_battery.py
```

Python 3.9+，只用标准库（tkinter 随官方安装包自带）。

打包成单文件 exe（需要 `resource/` 一起打进去）：

```bash
python -m PyInstaller --noconfirm endfield_battery.spec
```

或直接双击 `build_exe.bat`。产物在 `dist\`，图标与 `resource/logo.ico` 一致。

### 重新生成网页版

`web/index.html` 由 `web/template.html` + `resource/` 里的图片生成（只用标准库）：

```bash
python web/build.py
```

换了图片就重跑一次；只改文案/逻辑的话，`template.html` 和 `index.html` 两处都要改，或者改完模板重新生成。

## 搭建演示（网格蓝图）

右侧切到「搭建演示」，按当前结果画出游戏里那种竖排网格蓝图：

- 底部：左右各一个**仓库存货口**、中间一个**仓库取货口**；取货口正上方是**物品准入口**
- 一格就是游戏里的一格：传送带、拐角、汇流器、分流器各 1 格；仓库口占 1×3 三格（中间接线）；**热能池占 2×2**
- **普通分流**：一个分流器接 2 路输出即 1/2，接 3 路即 1/3，只保留一路继续往上接
- **质数分流**：汇流器 → (p+1) 分的因子链，把末级那一路回接到汇流器，即得 1/p；因子里的质数**递归展开**
- **因子顺序**：从下往上「输出口少的在下、多的在上」（比的是这个块最上面那个分流器有几个口），口数相同则较大的质数靠下。
  例：13 分 = 三个 2 分组成的 7 分块在下，再串一个 2 分在上
- **汇流器复用**：嵌套块的第一个因子正好坐在父块汇流器上时，回流直接并进父块那个（串联汇流器流量等价）
- **缓冲**：主链上「分流器 → 汇流器」直接贴住时垫一格（否则回流会堵住汇流器，本该往上走的电池被挤进返货支路）；
  汇流器下面是汇流器或拐角时不垫；入口 30 / 24 且准入口后接普通二分时，那个位置垫两格
- **返货支路**：左右各一条直线，整条线由汇流器串起来、不拐弯；主回路出来的返回带直接横着汇进汇流器，最下面接存货口
- **三分补口**：三分分流器只要有一个输出口没接上就会退化成二分、比例跟着错，缺哪侧就自动接到最近的返货通道
- 传送带交叉处自动放**物流桥**；两条支路抢同一个输出口时不硬画，而是给出提示
- 画完会压紧纵向上方的空行、裁掉左右空列

蓝图是用来照着摆的示意图，格子和朝向按截图逐格核对过，但实际摆放仍以游戏内为准。

## 目录结构

```
endfield_battery.py      桌面版（单文件，全部逻辑）
endfield_battery.spec    PyInstaller 打包配置
build_exe.bat            一键打包（GBK 编码）
resource/                运行需要的图片（电池图标、元件图、logo）
web/template.html        网页版可读源码
web/build.py             把模板 + 图片打成单文件 index.html
web/index.html           网页版成品（图片内嵌，可直接分发）
web/README.md            网页版单独说明
```

## 已验证到什么程度

- 桌面版：对 5 种电池 × 5 档速率 × 简单/精确 × 耗电 600~12000 的 4200 组参数跑过端口连通性自检
  （每个元件的每个输入/输出口是否真的接到东西），0 处不连通。
- 网页版：逻辑与桌面版逐行对照同步；如与实际摆放不符，欢迎提 issue 附截图。
