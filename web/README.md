# 终末地 · 电池配比计算器（网页版）

手机和电脑都能用，**一个 `index.html` 就是完整程序**（电池图片、logo、搭建演示元件图全部内嵌）。

## 怎么用

### 电脑
双击 `index.html`，用任意浏览器打开即可（Chrome / Edge / Firefox 都行）。

### 手机（Android / iPhone）
1. 把 `index.html` 传到手机（微信「文件传输助手」、数据线、网盘都行）；
2. 用 **Chrome** 打开它；
3. 菜单 → **添加到主屏幕**，桌面上就会出现一个「电池配比」图标，点开即用，和 App 一样。

> 手机浏览器直接打开本地文件时，图标会是浏览器的默认样式；
> 如果把它上传到任意静态托管（GitHub Pages、Vercel、自己的服务器…），
> 页面内置的 manifest 就会生效，添加到主屏幕后是**独立全屏**运行、有自己的图标。

## 功能

和桌面版完全一致：

- 三套配色：**黄灰（默认）/ 白蓝 / 黄紫**，右上角切换
- 电池种类下拉框，带图片，发电量自动带入
- 电池获取速率滑轨：6 / 12 / 18 / 24 / 30 个每分钟
- **简单模式**（2 分 3 分组合逼近）和**精确模式**（质因数分解配方）
- 右侧两种输出：**计算结果**（文字）和**搭建演示**（游戏内搭建方法）

## 搭建演示

右侧切到「搭建演示」，会按当前计算结果画出**游戏里那种网格蓝图**（竖排；
单链 9 列，全速双份时 13 / 15 列，画完会把两边空出来的列裁掉）：

- 底部：**左右各一个仓库存货口、中间一个仓库取货口**
- 取货口正上方固定放一个**物品准入口**（按当前电池种类出图，标签写明种类与速率），
  它和取货口、上面的汇流器/分流器之间不需要传送带中转（速率 30 / 24 且后面接的是
  普通二分时，两格缓冲放在二分和它上面那个汇流器之间）
- 回收支路是一条**直线**：整条线由汇流器串起来、不拐弯，主回路出来的返回带直接
  横着接进汇流器（最短一格），存货口入口在同一列上
- 网格里一格就是游戏里的一格：传送带、拐角、汇流器、分流器各占 1 格；
  仓库取货口 / 存货口占 1×3 三格，中间一格接线；**热能池占 2×2，箭头一侧朝下接入**
- **普通分流**：一个分流器接 2 路输出即 1/2，接 3 路即 1/3，只保留一路继续往上接
- **质数分流**：汇流器 → (p+1) 分的因子链，把末级那一路回接到汇流器，即得 1/p；
  如果因子里还有质数（如 44 = 2² × 11，11 里面又是 12 = 2×2×3），**会递归展开**
- **因子顺序**：从下往上「输出口少的在下、多的在上」（比的是这个块最上面那个分流器
  有几个口），口数相同的，较大的质数靠下。例：13 分 = 三个 2 分组成的 7 分块在下，
  再串一个 2 分在上
- **汇流器复用**：嵌套块的第一个因子正好坐在父块汇流器上时，不再单独立汇流器，
  回流直接并进父块那个（串联汇流器流量等价，主链 + 本块回流 + 父块回流正好三个口）
- **全速接法**（速率 24、30）：开头的质数分流器改成
  「**二分辨流 → 左右各搭一份完整质数分流器 → 汇流器合流**」，
  比例不变且不会堵塞；每份只有一条返回支路时用紧凑布局（回流走内侧、多余出口全朝外），
  需要第二条返回支路时才加内侧通道
- 传送带交叉处自动放**物流桥**；两条支路抢同一个输出口时不会硬画，而是给出提示
- **三分补口**：三分分流器只要有一个输出口没接上就会退化成二分、比例跟着错，
  所以缺哪侧就自动接到最近的返货通道
- 网格里的多余出口统一朝两侧返货通道，通道一条直线进存货口

蓝图较长时，右侧面板里可以用鼠标滚轮上下滑动；也可以点「放大查看 ↗」打开大图浮层，
用滚轮继续滚动、Ctrl/⌘ + 滚轮或右上角按钮缩放，Esc 关闭。

## 额外的小功能

页面支持用 URL 参数预置状态，方便分享特定配置，例如：

```
index.html?power=1500&battery=1&rate=18&theme=huangzi&mode=precise&view=build&calc=1
```

| 参数 | 说明 |
|---|---|
| `power` | 系统总耗电 |
| `battery` | 电池序号 0~4（0=谷底低容 … 4=武陵中容） |
| `rate` | 速率 6/12/18/24/30 |
| `theme` | `huanghui` / `bailan` / `huangzi` |
| `mode` | `normal` / `precise` |
| `view` | `result` / `build` |
| `calc=1` | 打开后立刻计算一次 |

## 改内容

- 直接改 `index.html` 即可（CSS 在最上面的 `<style>`，逻辑在最下面的 `<script>`）。
- 如果要换电池图片、logo 或搭建演示图片：替换 `../resource/` 里的图片，然后在本目录执行
  `python build.py` 重新生成 `index.html`（`build.py` 只用标准库，不需要装 Pillow）。
- `template.html` 是可读的源码模板，`index.html` 由它 + 图片生成。
